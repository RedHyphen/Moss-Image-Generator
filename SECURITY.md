# Security policy

Moss-Image-Generator is a portfolio artifact and is not an official hosted
service. Do not submit passwords, API keys, private prompts, personal images, or
other sensitive data in public issues or pull requests.

Before reporting a suspected vulnerability, verify that it is reproducible on
the current branch and include the affected component and safe reproduction
steps. Use a private GitHub Security Advisory when available; otherwise contact
the repository owner privately rather than publishing exploit details.

The project does not promise a response time or supported production versions.
